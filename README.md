# Zernex Video Player - Android (Media3 ExoPlayer & Jetpack Compose)

Zernex Video Player est un lecteur multimédia haute performance développé en Kotlin avec Jetpack Compose et AndroidX Media3 (ExoPlayer).

## Caractéristiques Clés
- 🚀 **Décodage Matériel HW+ (GPU / MediaCodec / Software fallback)**
- 🎛️ **Gestes tactiles avancés** (Luminosité à gauche, Volume à droite, Seek double-tap)
- 🔊 **Audio Booster jusqu'à 200% & Égaliseur 5 bandes**
- 💬 **Prise en charge multi-pistes & sous-titres avancés** (.srt, .vtt, .ass) avec réglage de délai
- 📺 **Regroupement intelligent des séries & animes** (S01E02)
- 📁 **Explorateur de dossiers média & analyse de stockage**
- 📊 **Statistiques complètes de lecture et métadonnées codec**

## Compilation & Installation Android
```bash
./gradlew assembleRelease
```
L'APK signé sera généré dans `app/build/outputs/apk/release/app-release.apk`.
